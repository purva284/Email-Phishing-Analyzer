
# Email Phishing Analyzer

## 1. Project Overview
Email Phishing Analyzer is a Python-based cybersecurity project designed to identify potential phishing emails. It analyzes the sender's email address and message content to calculate a risk score and identify suspicious email characteristics.

## 2. Aim
To develop a Python program that helps identify potentially suspicious and phishing emails through basic analysis.

## 3. Objectives
- Analyze sender email addresses.
- Examine email message content.
- Identify suspicious words and patterns.
- Calculate a phishing risk score.
- Display the risk level of an email.
- Generate a phishing analysis report.

## 4. Technologies Used
- **Programming Language:** Python
- **Platform:** Visual Studio Code

## 5. Key Features
- Sender email analysis
- Email content analysis
- Suspicious keyword detection
- Risk score calculation
- Risk level identification
- Automatic report generation

## 6. How to Run the Project

1. Install Python.
2. Open the project folder in Visual Studio Code.
3. Run the following command:

```bash
python phishing_analyzer.py
```

4. Enter the sender email address and email message when prompted.
5. View the phishing analysis results.

## 7. Output
The program displays a phishing risk score and risk level based on the email analysis. It also generates a report named `phishing_report.txt`.

## 8. Applications
- Basic phishing awareness.
- Identifying suspicious email messages.
- Understanding common phishing indicators.
- Learning cybersecurity concepts.

## 9. Disclaimer
This project is developed for educational purposes. It performs basic phishing analysis and cannot guarantee detection of every phishing email.
